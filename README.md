# Second Brain Apps

A one-page site for sharing the Second Brain apps with friends: **ChatBridge**, **OneNote Style** and **Brain Capture**.

Live at https://sundowna.github.io/sb/

## Direct links

Each app opens in its own panel, so you can send a link straight to one:

- https://sundowna.github.io/sb/#app/chatbridge
- https://sundowna.github.io/sb/#app/onenote
- https://sundowna.github.io/sb/#app/capture

## Files

- `index.html`: page content, sections and FAQ.
- `styles.css`: look, layout and the illustrated app previews.
- `app.js`: animations, sharing buttons and the app panels (text and install steps live in the `APPS` object).
- `assets/favicon.svg`: site icon.

No build step. The **Deploy Second Brain to GitHub Pages** workflow publishes every push to `main`.

The previous "Neural Edition" design is kept on the `neural-edition` branch.
